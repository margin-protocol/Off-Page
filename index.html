    PAGE 003 / TOOLS

    讓角色住進主畫面

    換上你的角色，她就一直在那裡。抬頭就看得到，不用打開任何 app。

    iPhone 主畫面小工具Scriptable範例角色・聞止水
    聞止水
    嗯。
    現在 --:--
    這是試玩：她會照你現在的時間說話，按按鈕碰碰她。
    WHAT SHE DOES

    她會做的事Features

    主畫面上的她

    • 小的、中的兩種尺寸都可以放
    • 中尺寸會顯示相遇第幾天和現在時間
    • 大約每半小時換一句話

    她會看時間說話

    照早中晚、星期、季節換台詞。01:30–08:30 是她的睡覺時間，會打哈欠。

    • 08:40醒了？
    • 12:15吃。
    • 18:40我在樓下。
    • 02:10……睡了。
    • 週一星期一。撐住。
    • 冬天很冷。手給我。
    • 生日生日快樂。

    點進去摸摸她

    摸頭、捏臉、牽手、碰她的耳骨環。每個地方的反應都不一樣。

    • 捏臉會臉紅，按相機她會拍你
    • 連續戳太多下，她會說「妳到底要戳幾下。」
    • 不用網路、不花額度

    跟她聊天

    點她說的那句話，直接打開聊天頁。

    • 用 Claude 說話，照她的個性回你
    • 她會換表情回你的訊息
    • 可以傳照片給她看
    • 重要的事她會記進記憶本
    • 手機、電腦都能接著聊
    CONTACT SHEET

    七種樣子Seven Looks

    跟著她說的話換表情。聊到拍照會舉起相機，說要出門會站起來。

    立繪和台詞都能換成你自己的角色。

    MAKE YOUR OWN

    做一個你自己的角色Make Your Own

    不用寫程式，也不用申請 API 金鑰。用你自己的 Claude 帳號，請 Claude 幫你做。

    先準備

    • Claude 帳號聊天會用到你自己帳號的額度
    • 角色設定個性、說話方式、你們的關係、她怎麼叫你
    • 角色圖片一張就可以；有不同表情更好，透明背景的 PNG 最好看
    • ScriptableApp Store 免費下載（iPhone）
    1. 請 Claude 做聊天頁 到 claude.ai 開新對話，把角色圖片和設定一起傳上去，再貼上右邊這段（〔〕裡改成你的）。做好後打開測試，第一次會問要不要允許頁面使用 Claude，按允許。哪裡不喜歡，直接跟 Claude 說要改什麼。 
      請幫我做一個手機用的角色聊天頁（artifact），讓我可以跟〔角色名〕傳訊息聊天。
- 用我自己的 Claude 帳號讓她回話，不要用 API 金鑰
- 聊天紀錄和記憶存在我的帳號裡，換裝置也看得到
- 有記憶本：她會自己記下重要的事，我也可以手動加、刪
- 可以傳照片給她看
- 上方放她的圖，回話時依心情換表情（用我附的圖片）
- 她的回話要像傳訊息：短、口語、不寫旁白和動作
- 配色：〔例如：深酒紅、黑色系〕
- 她叫我〔暱稱〕，我們的關係是〔關係〕

    2. 請 Claude 寫小工具 在同一個對話接著貼這段。Claude 會給你一段程式碼，打開 Scriptable 按右上角 ＋，整段貼上、取個名字存起來。 
      請幫我寫一個 Scriptable 主畫面小工具的程式碼：
- 顯示〔角色名〕的圖片和一句她現在會說的話
- 她說的話要照早中晚、星期、季節變化，符合她的個性
- 中尺寸顯示我們相遇第幾天（相遇日：〔日期〕）
- 點小工具會打開剛剛做好的聊天頁
    3. 放到主畫面 長按主畫面空白處 → 左上角 ＋ → 找 Scriptable → 選小或中尺寸加入。再長按小工具 → 編輯小工具 → Script 選你剛剛存的那個。

    沒有 Claude 帳號也可以

    下面兩段咒語也能丟給 ChatGPT、Gemini 這類 AI，請它幫你寫。選一種就好：

    OPTION A 自己接 API

    到 Google AI Studio（Gemini，有免費額度）或 OpenAI 申請一組 API 金鑰，讓聊天頁用你的金鑰回話。超過免費額度會依用量收費。

    • 金鑰只在聊天頁的設定裡輸入、存在自己手機上
    • 不要把金鑰寫進程式碼，也不要傳給別人看
    • 做好的網頁可以免費放在 GitHub Pages 或 Neocities，小工具再連過去
    請幫我做一個手機用的角色聊天網頁（單一 HTML 檔），讓我可以跟〔角色名〕傳訊息聊天。

- 頁面上有設定欄讓我輸入 API 金鑰，只存在這支手機的瀏覽器裡，不要寫進程式碼
- 聊天紀錄和記憶本也存在手機裡
- 上方放她的圖，回話時依心情換表情
- 她的回話要像傳訊息：短、口語、不寫旁白和動作

    OPTION B 只要小工具，不聊天

    她不會回你訊息，但主畫面上的她照樣會看時間說話、點進去也能摸摸她。不用任何帳號和金鑰，完全免費。

    • 台詞是事先寫好的，所以不花額度、不用網路
    • 想讓她多說一點，請 AI 幫你多寫幾句台詞就好
    請幫我寫一個 Scriptable 主畫面小工具的程式碼，不需要連網、不需要 API：
- 顯示〔角色名〕的圖片和一句她現在會說的話
- 依早中晚、星期、季節、我的生日（〔日期〕）換台詞，每個情境寫 5 句以上，符合她的個性
- 中尺寸顯示我們相遇第幾天（相遇日：〔日期〕）
- 點小工具會打開一個頁面，可以點她的頭、臉、手，每個地方有不同的小反應

    Hello, I'm Xia mumu.
